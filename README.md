# Truth or Dare 18+ (online, для двоих на расстоянии)

Веб-версия игры «Правда или Действие» 18+ для двух игроков из разных городов.
Открывается с любого Android-телефона по ссылке, без установки и регистрации.

**Live:** https://tod-game-backend-lrazjnti.fly.dev/

## Возможности

- Комната по 6-значному коду; никаких регистраций, никакого «белого IP» у игроков.
- WebSocket-синхронизация состояния в реалтайме.
- Уровень сложности (`Лёгкий флирт` / `Средний 18+` / `Hard 18+`) выбирается
  при создании комнаты и фиксируется на всю игру.
- На каждом ходу 3 кнопки:
  - **Выполнить** — засчитывает «выполнено» и передаёт ход.
  - **Отказаться** — засчитывает «отказ» и передаёт ход.
  - **Переключиться на Действие / Правду** — меняет тип задания без траты
    хода. Можно ходить туда-обратно сколько угодно, пока не нажмёшь Выполнить
    или Отказаться. Тексты Правды и Действия в рамках одного хода не
    пересоздаются при свапе.
- 300 уникальных вопросов (50 truth + 50 dare × 3 уровня), адаптированных под
  формат «партнёры в разных городах»: фото / селфи / голосовые / короткие
  видео в мессенджере / описать ощущения и т.п.
- **Скрытая прогрессия по тирам**: внутри каждого уровня вопросы делятся на
  три подгруппы — прелюдии (10) → средние (15) → горячие (25). Сервер
  переключает подгруппы по счётчику ходов с рандомными порогами (первая
  длится 7–10 ходов, вторая ещё 5–10). В UI это никак не показывается —
  ощущается только по тону вопросов.

## Стек

- **Backend:** FastAPI + WebSocket (одиночный процесс, состояние в памяти).
- **Frontend:** статичный HTML / CSS / vanilla JS, отдаётся тем же FastAPI
  из `backend/static/`.
- **Хостинг:** fly.io (Dockerfile и `fly.toml` генерируются деплой-скриптом).

## Структура

```
backend/
  main.py            # FastAPI + WebSocket логика
  questions.py       # Банк вопросов, тиры, выбор по turn_index
  static/            # Собранный фронт, который отдаётся в production
  pyproject.toml
frontend/            # Исходники фронта (синхронизировать со static/)
test_flow.py         # Локальный smoke-test (запускать против localhost:8000)
test_tier_progression.py  # 25 ходов через WS, проверка прогрессии тиров
```

## Локальный запуск

Требуется Python 3.11+.

```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -e .
uvicorn main:app --host 0.0.0.0 --port 8000
```

Открыть `http://localhost:8000/` в двух вкладках/устройствах.

## Тесты

```bash
# 1) полный цикл хода: choose → switch → switch → complete + второй игрок refuse
python test_flow.py

# 2) 25 ходов через WS, печатает таблицу «номер хода → тир → текст вопроса»
python test_tier_progression.py
```

Перед запуском тестов поднять локальный сервер (см. выше) и убедиться, что в
`test_flow.py` / `test_tier_progression.py` `BASE`/`WS` указывают на
`localhost:8000`.

## Деплой

Через сторонний инструмент Devin (`deploy backend`) или вручную: написать
`Dockerfile` (Python 3.12, `pip install .`, `uvicorn main:app --host 0.0.0.0
--port 8080`) и `fly.toml`, затем `flyctl deploy`.

## Безопасность / приватность

- Состояние комнаты живёт только в памяти процесса, никуда не пишется.
- Никакие сообщения / медиа партнёров не проходят через этот сервер — фото,
  голосовые и видео отправляются отдельно (Telegram / WhatsApp /
  видеозвонок). Сервер хранит только тексты вопросов и счёт.
- Комната автоматически забывается, как только оба игрока отключаются и
  процесс переезжает / рестартует.
